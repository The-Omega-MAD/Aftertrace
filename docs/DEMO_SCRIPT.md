# Three-minute live demo

## 0:00–0:25 — The problem
“An incident response team may investigate the same application more than once. The danger is not just forgetting the old case. It is remembering the old conclusion and applying it to new evidence.”

Show the AFTERTRACE landing screen.

## 0:25–0:55 — First investigation
Click **Connect Hindsight**. Click **Seed first investigation into Hindsight**. Explain that AT-001 records an approved integration, no new permission grant, and a cautionary lesson.

## 0:55–1:45 — New alert
Show AT-002. It concerns the same application, but a permission change is now present and the actor context is unverified. Click **Recall history + generate Evidence Delta**.

## 1:45–2:30 — Show memory
Show the recalled memory and Hindsight reflection. Point out the same application, changed permission event, unverified actor context, and why the previous outcome is not inherited.

## 2:30–3:00 — Learning loop
Enter an analyst finding, lesson, and outcome. Click **Retain analyst feedback in Hindsight**.

Close: “AFTERTRACE remembers what the team learned, but makes the analyst re-check what changed. Memory should improve the investigation, not decide it.”
