# AFTERTRACE — three-minute video script

## Video title
**The Same Alert Is Not the Same Incident | Hindsight Memory Demo**

## 0:00–0:25 — Intro
**On screen:** AFTERTRACE landing page.

“Hi, I'm Michael, and this is AFTERTRACE. It is an incident-continuity assistant built around Hindsight. The idea is simple: a security team should remember what it learned from an earlier investigation, but it should never blindly reuse the earlier conclusion.”

## 0:25–0:55 — Problem
**On screen:** Show synthetic incident AT-001.

“Here, an OAuth application was checked and approved in one specific investigation. No new permission grant was recorded. That result is useful, but it is not a permanent trust certificate for every future event involving the same application.”

## 0:55–1:30 — Retain
**On screen:** Click Connect Hindsight, then Seed first investigation into Hindsight.

“AFTERTRACE retains the incident observations, analyst finding, lesson, and outcome in a Hindsight memory bank. The next investigation can retrieve this information.”

## 1:30–2:20 — Recall and reflect
**On screen:** Show AT-002, with the new permission change and unverified actor context. Click Recall history + generate Evidence Delta.

“Now the same application appears again, but this event includes a permission change and an actor context that has not been verified. AFTERTRACE asks Hindsight to recall relevant prior investigations and reflect on the new evidence.”

Show the comparison and recalled memory.

“Notice what changed. The entity matches, but the permission event and approval context do not. The old benign outcome is not copied into this incident.”

## 2:20–2:45 — Analyst feedback
**On screen:** Enter an analyst finding, lesson, and outcome. Retain feedback.

“The analyst reviews the evidence, records the finding, and retains the lesson. That feedback becomes context for future investigations.”

## 2:45–3:00 — Close
**On screen:** AFTERTRACE title.

“AFTERTRACE remembers the incident, re-checks the evidence, and keeps the decision with the analyst. Hindsight is what makes that continuity possible.”
